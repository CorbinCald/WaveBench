# Wave animation preview

![WaveBench's three water layers with thin irregular crests, soft caustic highlights, and fine CRT texture](assets/wave-animation.gif)

All three waves roll through thin, uneven crests with small surface ripples, moving caustics, and fine CRT texture. The middle wave has softer highlights; the far wave is dimmer with finer, lighter texture. These differences keep the depth visible even in reduced-color terminals. The background water moves more slowly. A narrow gap follows each nearer crest, keeping rear-water dots from crowding its outline where the waves cross. Height, brightness, and motion build as output arrives.

This recording shows the actual terminal progress display in the Blueberry theme, using simulated streaming updates.
